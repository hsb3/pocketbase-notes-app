# Implementation Plan: Open tasks from entry checklists

**Branch**: `overhaul/tasks` | **Date**: 2026-11-15 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/001-open-tasks/spec.md`

## Summary

Unchecked checklist items (ProseKit `list` nodes with `kind: "task"`) become tasks. The existing entry
validation hook derives `open_tasks` (count) and `tasks` (`[{path, text}]`) on every save; a migration adds
the fields and backfills them with SQL (no `updated` bump, no revision bump). A new `/entries/tasks` route
lists entries with `open_tasks > 0`, requesting only index fields. Ticking an item fetches that one entry,
flips `checked` at `path`, and saves with the revision the list showed, so the existing 409 path guards it.

## Technical Context

**Language/Version**: TypeScript (React 19, TanStack Router), PocketBase 0.40.x JSVM hooks (ES5-ish goja)

**Primary Dependencies**: existing only — `pocketbase` SDK ^0.28, shadcn primitives, ProseKit

**Storage**: PocketBase SQLite; `entries` gains `open_tasks` (number) and `tasks` (json)

**Testing**: `scripts/test-entries.ts` (API, live stack); Playwright `tests/e2e/tasks.spec.cjs`

**Target Platform**: browser (chromium + webkit, desktop 1440px + mobile 390px)

**Project Type**: web application (single repo: `src/` frontend, `pb/` backend)

**Performance Goals**: Open tasks request transfers no entry bodies

**Constraints**: no new dependencies; ownership rules unchanged; generated types only via `make codegen`

**Scale/Scope**: personal notebook; tens to low thousands of entries per user

## Constitution Check

| Principle | Status |
|-----------|--------|
| I. Backend before frontend | Migration + hook + codegen first (tasks T001–T005) |
| II. Locked by default, server-enforced | Count/list derived in `onRecordValidate`; rules untouched; isolation tested |
| III. Never lose a user's words | Tick reuses `revision` 409 check; e2e covers editor draft vs tick |
| IV. Smallest change, no deps | Native checkbox (no `checkbox.tsx` in `src/components/ui`, outside lane) |
| V. Verified for real | API test + Playwright against `pbn-tasks` stack |

Re-check after design: no violations.
