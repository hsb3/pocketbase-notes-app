Responsive behavior

Single-column projects. Stacked search and filters. Secondary actions in overflow menus. Dialogs scroll inside the viewport.

Detail pages keep the same reading order: title, status, notes, attachment, destructive action.

Status has a text label. Checkboxes and linked titles are separate keyboard targets. The mobile list shows the same records and filters as desktop.
